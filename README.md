# Rock Paper Scissors 🎮

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer and test your luck!

## 🚀 About the Project

This project is a browser-based implementation of the classic Rock Paper Scissors game. It was built as a hands-on project to practice frontend development and strengthen JavaScript fundamentals.

## ✨ Features

- Play against the computer.
- Choose between Rock, Paper, and Scissors.
- Random computer selection.
- Automatically determines the winner.
- Displays game results.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Open the game in your browser.
2. Choose Rock, Paper, or Scissors.
3. The computer will randomly select its move.
4. The winner is decided based on the following rules:

| Your Move | Computer Move | Result |
|---|---|---|
| Rock | Scissors | You Win |
| Paper | Rock | You Win |
| Scissors | Paper | You Win |
| Same choices | Same choices | Draw |

## 💻 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/mokshaldoshi/Rock-Paper-Scissors.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Rock-Paper-Scissors
   ```

3. Open `index.html` in your browser.

   You can also use the Live Server extension in VS Code.
