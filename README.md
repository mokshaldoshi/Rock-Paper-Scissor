# ✊ Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer, track the score in real-time, and enjoy a clean and responsive user interface.

---

## 🚀 Features

- 🎮 Play Rock, Paper, and Scissors against the computer.
- 🤖 Computer generates random moves.
- 📊 Live score tracking for both player and computer.
- 💬 Displays the result.
- ⚡ Fast and lightweight with no external libraries.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
